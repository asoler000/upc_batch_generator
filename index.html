The QR encodes https://id.gs1.org/01/<GTIN-14> — the GTIN you already have, expressed as a web link, so a phone camera opens it with no app. It is a second, separate deliverable and never replaces the UPC.
QR module size is just how many pixels each square is drawn at in the exported file; the 4-module quiet zone is what has to survive printing, so never crop the white border.
"Will it scan?" is the one that matters for print. Give it the width you actually have on the panel and it tells you the physical size of one square — the number that decides whether a customer's phone can read it. A code can look perfect in Illustrator and still be unreadable.

Every file is named MODELNUMBER_UPCNUMBER — for example MODEL-1001_012345678905.svg. The 2D files append _GS1-DIGITAL-LINK so the two kinds can never be confused. Each ZIP also carries a 00_README.txt listing every code, its symbology and its exact printed size.

What is a “2D GS1 Digital Link code”? A QR code is the shape (a grid of squares, so it holds far more than bars). 2D just means data in two directions, unlike a one-line UPC. And GS1 Digital Link is the rulebook for what goes inside it: your same existing GTIN, written as a web address — https://id.gs1.org/01/00012345678905 — so a phone camera can open it with no app. One number, a second alphabet.
Which code do I actually need? The UPC is what a retail checkout scanner reads today and is still required on packaging. The 2D code is the additional code heading for retail point-of-sale over the coming years: the same GTIN carried as a link so a phone can open it. Retailers adopting it upgrade their scanners; that is their change, not yours. Keep both on the artwork. A 2D code is additive, never a substitute, and the two are generated as separate downloads so neither can be placed by mistake.
Why bother? A UPC's 12 digits can only identify the product. A Digital Link can also carry batch and expiry inside the code, and can lead your customer somewhere useful — that is the difference between a compliance mark and something that sells.
Illustrator note: browsers cannot write Adobe’s proprietary .ai format. The generated SVG is true vector — open it in Illustrator and it comes in as editable paths plus real text, then File → Save As → Adobe Illustrator (.ai) if that is what your workflow needs. For placing directly into packaging art, the PDF is the safer choice because it keeps the exact physical size.
